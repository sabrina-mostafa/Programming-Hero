
## Steps:
1. `npm init -y`
 - creates *package.json*
2. `npm install -D typescript ts-node @types/node`
 - packages are installed as dev dependencies
3. create src/server.ts
4. create src/config
5. `npx tsc --init` or `tsc --init`
 - creates a `tsconfig.json` file
6. fix tsconfig.json as per need
7. create .env file
