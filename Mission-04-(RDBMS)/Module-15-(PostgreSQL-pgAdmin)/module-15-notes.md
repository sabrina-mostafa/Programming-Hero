
## Basic sql commands for postgreSQL:
* to run on SQL shell
\! cls (to clear)
\l (to see all table list)
\conninfo (to see connection info)
\dt (to see tables)
\du (to see all users)
\? (to see all existing commands)
select version(); (to see the version)
select current_date; (to see  current date)
\c template1  (to connect to template1)
\c postgres (to connect to postgres)


* to run PostgreSQL through PowerShell
psql -U postgres(user name) -d postgres(database name)
